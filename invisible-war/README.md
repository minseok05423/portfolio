## 1. 공모전 개요

- **과제:** 병영문화혁신 "5관 3략" 홍보 UCC, 2분 내외
- **5관 (5대 자기관리):** 음주 · 이성 · 금전 · 말 · 보안
- **3략 · 3가지 없애기:** 구타·가혹행위 / 폭언·욕설·인신공격 / 질책·사생활 침해
- **3략 · 3가지 잘하기:** 존중·배려 / 칭찬·감사·웃어주기 / 전우사랑

## 2. 컨셉

- **한 줄 요약:** 무장 출동한 수색조가 부대 곳곳에서 사건의 흔적을 발견한다. 흔적마다 "핏" 하고 과거가 스치고, 적은 끝내 보이지 않는다. 지휘관의 한마디 뒤 시간은 사건 직전으로 되감긴다.
- **핵심 대사 (지휘관, 목소리만):** "우리가 경계해야 할 것은 눈에 보이는 적만은 아니다."
- **마무리 슬로건:** "5관 3략, 병영을 지키는 또 하나의 경계 태세."

## 3. 주요 결정과 이유

| 결정 | 이유 |
|---|---|
| 출동과 문제 행동을 **교차 편집**하고, 사이를 "핏" 소리로 잇는다 | 출동의 긴박함이 끝까지 유지되고, "보이지 않는 전쟁"이 연출로 드러남 (v1은 상황을 순서대로 나열해서 중간에 긴장이 풀렸음) |
| 수색조는 행동이 아니라 **행동 뒤에 남은 흔적**을 발견한다 (현재), 행동 자체는 **플래시** (과거) | 무장 장병이 다른 장병을 "감시"하는 그림을 피하고, 수사물 같은 추리 긴장을 만듦 |
| 정상화는 **되감기**로 사건 직전으로 돌아가 수색조가 직접 개입 | 같은 장소·같은 앵글로 전후를 대비해 "우리가 바꾸면 흔적도 사라진다"를 대사 없이 전달 |
| 부대원 대사: "흔적은 있는데… 적이 없습니다." | 지휘관 대사로 자연스럽게 이어짐 |
| 마지막에 무전 "…상황 종료." | 무전으로 시작해 무전으로 끝나는 수미상관 |
| 전반부는 어둡게, 정상화는 밝고 따뜻하게 | 지휘관 대사 이후 빛·색·BGM이 함께 바뀌며 반전이 화면으로 전달됨 |
| **오프닝 무장 장면(#2–5)은 AI 영상으로 생성** | 실제 촬영에서 총기를 불출할 수 없음 |
| 총은 AI 오프닝에만 등장. 실제 촬영(#6–)에서 수색조는 헬멧·전투조끼·손전등만, 총은 화면 밖 | 얼굴·대사가 나오는 컷은 실제 배우로 찍어야 일관성 유지. #31은 "헬멧과 손전등을 내려놓는다"로 변경 |
| **사운드는 전부 AI로 제작** (BGM, 효과음, 목소리) | |

### 긴장 BGM 생성 프롬프트 (55초로 생성 후 편집에서 0:52에 자르기)

```
Cinematic military thriller underscore, instrumental only, no vocals. D minor, 100 BPM, 55 seconds.

0:00–0:05 — Dark sub-bass drone with faint radio static and distant metallic hum. No drums. Ominous and still.
0:05–0:12 — Sudden deep taiko hit, then tight snare rolls and a driving low pulse enter. Urgent, like soldiers deploying.
0:12–0:32 — Pull back to a minimal heartbeat-like low pulse and a soft ticking clock. Very sparse, lots of empty space, cold and investigative.
0:32–0:48 — Staccato cello and viola ostinato joins, layered with low brass swells. Tension rises steadily, pressure building.
0:48–0:55 — Full orchestral hits, pounding percussion and a steep rising riser to maximum intensity, then an abrupt hard stop with no reverb tail.

Mood: tense, suspenseful, dark, cinematic, investigative. Avoid: melody-heavy themes, heroic or triumphant feel, electronic dance beats.
```

0:12–0:32 구간은 현장음이 올라갈 자리라서 일부러 비워 둔다.

### ElevenLabs 구간 나누는 법
1. 프롬프트 하나에 시간대별 구성을 적어서 생성 (위 프롬프트처럼). 가장 간단함.
2. 생성 후 편집 화면 타임라인에서 구간을 골라 스타일 태그 수정, 길이 조절, 그 구간만 재생성.
3. 안 되면 구간별로 따로 생성해 캡컷에서 이어 붙이기. 모든 프롬프트에 같은 조성·속도(`D minor, 100 BPM`)를 넣는다.
- 참고: API의 composition plan은 구간별 길이를 ms 단위로 지정 가능 (구간당 3초~2분).
- 이미 만들어진 곡(후보 3곡)은 이 기능과 무관하고, 편집 프로그램에서 잘라 맞춘다.

### ⚠️ 라이선스 (결제 전 확인)
- ElevenLabs **무료 요금제로 만든 음원은 개인·비상업 용도만 허용.** 출처 표기를 해도 상업적 이용 불가.

  3. ElevenLabs 고객지원에 공모전 사용 가능 여부 문의, 답변 캡처.

## 7. 촬영 메모

- **샷 표기:** W.S 와이드 · F.S 풀 · K.S 니 · M.S 미디엄(허리 위) · B.S 바스트 · CU 클로즈업 · O.S 어깨 너머. v1에서 W.S를 와이드/웨이스트 두 뜻으로 섞어 써서 웨이스트 샷은 M.S로 통일.
- **어두운 장면:** 너무 어둡게 찍지 말고 적당히 찍은 뒤 편집에서 어둡게. 노출·초점 고정(AE/AF 잠금), 디지털 줌 금지.
- **휴대폰 조명:** 휴지·A4·흰 비닐로 빛을 퍼뜨리고, 흰 벽에 반사하고, 정면이 아닌 45도 옆·위에서 비춘다.
- **장면 속 원래 빛 활용:** 손전등(수색), 복도 조명 하나(폭언), 휴대폰 화면(도박), 모니터(보안), 햇빛(정상화).
- **AI 오프닝:** 얼굴 없이 손·군화·역광 실루엣만. 어둡게 만들고 실제 촬영분과 같은 색 보정을 씌운다.
- **주의:** 총구가 아군을 향하지 않게, 구타는 그림자와 소품으로만 암시, 도박·메신저·복사 완료 화면은 직접 만든 가짜 화면, 보안 시설·문서가 화면에 잡히지 않게. 부대 내 촬영 승인 필수.
- **미리 만들 가짜 화면:** 빚 독촉 알림 (#12), 도박 사이트 (#14), "복사 완료" 창 (#17), 단톡방 (#22)
- **편집 (캡컷):** 플래시는 흰 화면 2프레임 + 효과음 피크를 컷에 맞추고 채도를 낮추고 소리는 로우패스. 되감기는 역재생 + 속도 램프 + VHS/글리치 약하게.

## 8. Higgsfield 기록

- 무료 플랜. 시작 7.48 크레딧 → v1 콘티 이미지 22장(Z Image, 장당 0.15) 생성 후 **약 4.2 크레딧 남음**.
- 이미지 생성은 동시 요청 제한(429)이 있어 2~3장씩 나눠 보내야 함.
- 영상 생성 비용: Kling 3.0 Turbo / Kling 3.0 3초 클립 4.5 크레딧, Seedance 2.5 4초 480p 12 크레딧. **현재 크레딧으로는 영상 1컷도 불가.** AI 오프닝(3~4컷, 재생성 포함)에는 20~30 크레딧 필요.
